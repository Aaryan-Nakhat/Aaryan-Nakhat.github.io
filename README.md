# aaryan-nakhat.github.io

Personal portfolio. Plain HTML/CSS/JS. Hosted on GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

Push to `main` of `Aaryan-Nakhat/Aaryan-Nakhat.github.io`. Enable Pages: Settings → Pages → Source = `main` / `/`.
